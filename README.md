# Progetto di Red Teaming - VAPT
Esame Laboratorio di Sicurezza dei Sistemi e Privacy

Il seguente repository illustra il progetto svolto per l'esame del corso 'Laboratorio di Sicurezza dei Sistemi e Privacy'.
Al suo interno si troveranno:
- juice_shop_evidence_package , una cartella zippata nella quale saranno illustrati gli output dei diversi tool utilizzati durante il progetto e gli screenshot raccolti durante le varie fasi;
- Comandi.txt ovvero un foglio di testo il quale raccoglie i comandi utilizzati per la fase di Information Gathering;
- RelazioneVapt.pdf ovvero la frelazione, in formato pdf, che racchiude la spiegazione delle operazioni svolte.
